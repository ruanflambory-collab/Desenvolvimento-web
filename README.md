# Desenvolvimento-web
Olá! Sou estudante de Análise e Desenvolvimento de Sistemas (ADS) e atualmente estou estudando a linguagem Rust em uma disciplina do curso, com foco em desenvolvimento web.

Estou aprendendo como Rust pode ser utilizada na criação de aplicações web, conhecendo conceitos como back-end, APIs, segurança, desempenho e gerenciamento de memória. É uma experiência interessante, pois estou tendo contato com uma linguagem diferente e entendendo como ela pode ser aplicada no desenvolvimento de sistemas web modernos.

Ainda estou no processo de aprendizado, mas estou gostando bastante de explorar as possibilidades do Rust no desenvolvimento web.
